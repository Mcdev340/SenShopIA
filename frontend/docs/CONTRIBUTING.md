# Contribuer

1. Créez une branche descriptive depuis la branche principale.
2. Conservez les types existants et préférez les composants UI partagés.
3. Lancez `npm run type-check` avant chaque pull request.
4. Ajoutez un test pour toute logique métier nouvelle.
5. Décrivez le comportement attendu, les changements et les vérifications effectuées.

Les secrets et fichiers `.env*` ne doivent jamais être commités.
